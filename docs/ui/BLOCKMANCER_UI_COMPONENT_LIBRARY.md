## Asset key/fallback rules
Each component uses its own asset key and category fallback. Dynamic labels, values, costs, quantities, and localized strings are game text.

## Pixel-perfect or QA guidance
Component exports must match expected size, use nearest filtering, preserve safe padding, and keep zIndex below text/control overlays where required.

## Status / known gaps
This library defines the contract. Some final art is not present yet; fallback placeholders remain valid until production assets land.
