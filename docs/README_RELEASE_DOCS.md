# How to use this documentation pack

1. Copy all `.md` files into your project `docs/` folder.
2. Keep `01_GDD_MASTER.md` as the source of truth for product vision.
3. Use `10_PRODUCTION_ROADMAP.md` to plan milestones.
4. Use `11_QA_TEST_PLAN.md` and `17_DEFINITION_OF_DONE.md` before each release candidate.
5. Update these docs whenever gameplay, content, platform, or monetization changes.

Recommended immediate next step:

```text
1. Add SettingsScene and CreditsScene if missing.
2. Add ASSET_PIPELINE support if missing.
3. Expand content to Content Alpha targets.
4. Start QA smoke checklist after every build.
```
