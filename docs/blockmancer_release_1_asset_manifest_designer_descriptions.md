# Blockmancer Dungeon - Release 1.0 Asset Manifest with Designer Descriptions

## Purpose

This designer-facing checklist is aligned to the actual asset keys currently used by the project code, content JSON, preload manifest, and `public/assets` tree. The current project names are the source of truth; older generated names are kept only as planned backlog rows or mismatch notes.

Inventory refreshed: 2026-05-15.

## Current Runtime Rules

- Use lowercase snake_case keys.
- Current preload source is `src/game/data/assets.ts`. It builds content image paths from JSON asset fields.
- Current public runtime paths are rooted at `public/assets/`, while Phaser loads paths without the `public/` prefix.
- `AssetSystem` generates missing image fallbacks for `asset_missing`, `asset_missing_icon`, `asset_missing_block`, and `asset_missing_background`.
- `AudioSystem` synthesizes fallback tones if listed SFX files are missing.
- Do not rename content IDs, JSON asset keys, or files from this document alone; use the mismatch notes as rename recommendations.

## Status Values

| Status | Meaning |
| --- | --- |
| Exists in project | Key is referenced/declared and the expected physical asset file exists. |
| Planned / Missing in project | Legacy planned checklist key is not currently referenced or declared. |
| Referenced / Missing physical file | Key is used by code/JSON/manifest, but the expected file is missing. |
| File exists / Not referenced | Physical file exists under `public/assets`, but no code/JSON/manifest reference was found. |
| Naming mismatch | Same concept has different naming between legacy markdown and current runtime/content. |
| Duplicate / Needs cleanup | Same key or concept appears with duplicate/conflicting paths or rows. |
| Placeholder fallback | Safe placeholder key or generated fallback behavior. |
