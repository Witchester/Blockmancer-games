# Legal / IP Risk Notes

This is practical production guidance, not legal advice. Consult a qualified attorney before commercial release if risk tolerance is low.

## 1. Main risk

The game uses falling-block mechanics. The safest direction is to avoid copying the expression, branding, assets, UI, terminology, audio, and visual identity of any existing falling-block game.

## 2. Safer positioning

Use:

```text
falling-block combat roguelike
block puzzle RPG
magical rune block battler
```

Avoid:

```text
using protected brand names in title
store copy that presents the game as a direct clone
screenshots that look like a classic falling-block clone
copied assets/audio/fonts/UI
```

## 3. Originality requirements

Make these visibly original:

```text
game title
logo
block art
board frame
UI/HUD
monster design
spell icons
audio
map/reward systems
terminology
store screenshots
```

## 4. Game mechanics vs expression

Game rules and general methods of play are usually treated differently from the specific expressive implementation. However, copying the specific look and feel of a well-known game can still create legal risk.

## 5. Practical risk reduction checklist

```text
[ ] Do not use protected brand terms in title/app name
[ ] Do not use third-party art/audio/code without license
[ ] Use own block shapes/visuals/terminology where possible
[ ] Make combat and roguelike systems central in screenshots
[ ] Avoid classic piece colors as sole identity
[ ] Use original UI skin and dungeon theme
[ ] Keep proof of asset licenses
[ ] Keep credits/licenses file updated
```

## 6. Store review risk

Even if legal risk is low, store reviewers or users may perceive a game as a clone if screenshots and copy are too similar to known games. Visual differentiation matters.

## 7. Content rating considerations

Blockmancer Dungeon likely involves fantasy violence against monsters. Ratings may vary by region and store questionnaire answers.
