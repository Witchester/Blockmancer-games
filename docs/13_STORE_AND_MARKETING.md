# Store and Marketing Plan

## 1. Positioning

Do not position the game as a clone. Use:

```text
falling-block combat roguelike
block puzzle RPG
arcade puzzle dungeon crawler
spellcasting block battler
```

Avoid using protected brand terms in title or primary marketing copy.

## 2. One-line pitch

```text
Clear magical block lines to damage monsters, cast spells, collect relics, and survive a cursed roguelike dungeon.
```

## 3. Short store description

```text
Blockmancer Dungeon is a falling-block combat roguelike where every line clear becomes a magical attack. Fight monsters, cast spells, choose powerful relics, and survive a dungeon that keeps changing the rules of your board.
```

## 4. Long store description outline

```text
You are a Blockmancer, a mage trapped in a cursed dungeon.
Clear rune lines to strike enemies.
Gain mana and cast spells to control the board.
Face monsters that throw junk, hide previews, shake the board, and speed up gravity.
Choose relics and upgrades after each fight.
Plan your route through a roguelike map.
Defeat the Falling King.
```

## 5. Key features

```text
Falling-block combat system
Monster intents and board disruption
Mana-powered spellcasting
Roguelike reward builds
Special rune blocks
Short replayable dungeon runs
Desktop and mobile-friendly controls
```

## 6. Screenshot plan

Required screenshots:

1. Battle board with enemy and spell UI.
2. Big spell cast / explosion.
3. Reward selection screen.
4. Roguelike map.
5. Boss fight.
6. Hero select / build identity.

## 7. Trailer structure

30–45 seconds:

```text
0–3s: title + hook
3–10s: line clear damages enemy
10–18s: spells and special blocks
18–25s: enemy disrupts board
25–33s: rewards/builds/map
33–40s: boss moment
40–45s: release/platform CTA
```

## 8. Store art assets

Prepare:

```text
app icon

screenshots
trailer thumbnail
press kit images
```

```

```

## 12. App/store keywords

Use genre/descriptive keywords:

```text
puzzle
roguelike
block puzzle
RPG
spell combat
dungeon
arcade
strategy
```

Avoid making protected brand terms the main discovery strategy.
